# 体力计算助手 (astrbot_plugin_stamina_calculator)

本插件专为游戏玩家设计，用于精准计算游戏体力的回复时间。支持自定义体力上限，并根据实时回复进度推算回满时刻。

## 插件简介
* **名称**：l体力计算器
* **版本**：1.0.0
* **作者**：luban652
* **分类**：工具、游戏

---

## 功能说明
1.  **灵活上限设定**：支持 25 点或 50 点体力上限切换，适配不同阶段的游戏需求。
2.  **精准时间推算**：基于 30 分钟/点的回复速率，结合当前回复进度，精确计算回满所需的分钟数及具体的现实时刻。
3.  **持久化存储**：使用本地数据库记录每个用户的体力上限设置及当前任务状态。
4.  **状态实时查询**：支持随时查看已记录的体力恢复倒计时。

---

## 插件流程
插件内部遵循以下逻辑工作流：

1.  **数据初始化**：插件启动时，在 `data` 目录下初始化数据库，用于存储用户的个性化配置（上限、任务状态）。
2.  **指令捕获**：
    * 当用户输入 `/上限` 时，更新数据库中该用户的 `max_stamina` 字段。
    * 当用户输入 `/火 [当前] [剩余]` 时，插件通过以下公式计算：
        $$TotalMinutes = (Max - Current - 1) \times 30 + Remaining$$
    * **时间转换**：将总分钟数加至当前系统时间，得出"回满现实时间"。
3.  **状态查询**：`/火 当前` 会通过当前时间与记录的回满时间进行对比，动态返回剩余差值。

---

## 使用方法

### 1. 设置体力上限
在使用计算功能前，请先设置你的游戏体力上限。
* **指令**：`/上限 [25|50]`
* **示例**：`/上限 25` 或 `/上限 50`

### 2. 计算回复时间
输入当前的体力数值及距离下一点回复还剩多少分钟。
* **指令**：`/火 [当前体力值] [距离下一点回复剩余分钟]`
* **示例**：`/火 10 15`
    * *表示当前 10 点体力，还有 15 分钟回复第 11 点。*

### 3. 查询当前状态
查看已设置的体力恢复任务及预计回满时间。
* **指令**：`/火 当前`

### 4. 获取帮助
快速预览所有指令。
* **指令**：`/火help`

---

## 配置说明
本插件主要通过指令进行用户侧配置，无需手动修改配置文件。所有用户数据均存储于 `data/stamina_user_data.json` 文件中。

| 配置项 | 默认值 | 说明 |
| :--- | :--- | :--- |
| 体力上限 | 25 | 用户未设置时的初始值 |
| 回复速率 | 30分钟/点 | 插件内置固定参数 |
| 任务持久化 | true | 重启后自动恢复未完成的任务 |

---

## 注意事项
* **回复速率固定**：本插件严格按照 **30 分钟回复 1 点** 的逻辑计算，暂不支持自定义回复速度。
* **时间同步**：计算基于机器人所在服务器的系统时间，请确保服务器时间准确。
* **数据存储**：用户数据以 JSON 格式保存在插件目录下，卸载插件前建议备份。

---

## 开发者信息
* **依赖项**：无额外第三方库依赖（基于 AstrBot 标准 API）
* **核心功能**：根据当前体力、下一点回复剩余时间，计算体力回满的现实时间。
